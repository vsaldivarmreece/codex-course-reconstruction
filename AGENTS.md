# Agent Instructions

## Knowledge Memory

This workspace uses `knowledge/` as its local derived memory for source research, AI trends, implementation patterns, monetization ideas, and process improvements.

Before analyzing YouTube, Reddit, articles, docs, or other external sources for this project:

1. Read `knowledge/README.md`.
2. Store raw source exports under `knowledge/raw/`.
3. Store normalized transcripts, threads, summaries, and extracted insights under `knowledge/processed/`.
4. Link useful findings back to project areas in `knowledge/projects/ia-learning/`.
5. Keep evidence traceable with source URL, captured date, source type, confidence, and relevant timestamp or permalink.

Do not treat generated summaries as primary evidence. Preserve the raw source payload or source link whenever possible.

If this convention is used from another workspace, keep only a lightweight pointer there and use this repo as the first local reference until a shared Supabase knowledge hub exists.
