# Sprint 1 - Core Workflow

Objetivo: reproducir el workflow de Codex antes de construir producto grande.

## Tareas

- Definir la estructura minima de monorepo.
- Versionar prompts educativos sugeridos.
- Crear primer runbook operativo.
- Decidir convenciones de evidencia y validacion.
- Preparar el primer prompt de scaffold para `apps/web`.

## Done when

- el equipo puede arrancar el proyecto sin discutir estructura;
- existe una bitacora de prompts por sesion;
- hay un prompt base listo para comenzar `apps/web`.
