# Docs

Documentacion viva del proyecto.

- `specs/`: PRD y documentos de definicion.
- `evidence/`: matrices y notas de verificacion contra el video.
- `backlog/`: iniciativas, milestones y tareas.
- `runbooks/`: pasos operativos y flujos repetibles.
- `skills/`: convenciones para investigadores, plugins y agentes.

## Memoria derivada

La investigacion reutilizable de YouTube, Reddit, fuentes web, novedades de IA, ideas de monetizacion y patrones tecnicos vive en `../knowledge/`.

Usa `docs/` para decisiones, evidencia formal y documentacion del proyecto. Usa `knowledge/` para capturar, normalizar e indexar material externo antes de promoverlo a backlog, PRD o implementacion.
