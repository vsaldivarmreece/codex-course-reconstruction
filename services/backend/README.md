# services/backend

Backend del proyecto y punto natural para integraciones, persistencia y flujos MCP relacionados con la reconstruccion educativa.

Supuesto de stack:

- `Supabase` como backend principal;
- MCP como capa de acceso/inspeccion guiada por Codex;
- scripts y configuracion local mas adelante, despues de validar evidencia y prompts.

Responsabilidades esperadas:

- modelo de datos del MVP web;
- autenticacion y datos de prueba;
- integraciones necesarias para demos y validacion;
- documentacion operativa del flujo MCP.
